# Gestão do projeto

Esta pasta reúne os documentos que orientam a organização, o acompanhamento e a execução do projeto Tirador de Pedidos do NEO.

Seu objetivo é manter as regras de trabalho acessíveis a todos os times e registrar como o projeto será conduzido ao longo das Sprints.

## Documentos disponíveis

- [`definition-of-ready.md`](./definition-of-ready.md): critérios mínimos para que uma Issue possa sair do Backlog e ser iniciada.
- [`definition-of-done.md`](./definition-of-done.md): critérios mínimos para que uma entrega possa ser considerada concluída.

## Aplicação

As orientações desta pasta são válidas para Produto, UI/UX, Frontend, Backend e Banco de Dados.

Quando um repositório técnico possuir uma regra específica, ela deverá complementar estas orientações, sem contradizer o processo geral definido no repositório central.

## Responsabilidades

- O Scrum Master mantém a organização geral dos documentos de gestão.
- Os líderes de cada time ajudam a revisar e aplicar as regras.
- Cada integrante é responsável por manter suas Issues, Pull Requests e evidências atualizadas.
- Mudanças relevantes no processo devem ser discutidas com os líderes e registradas neste repositório.

## Fonte oficial

- O GitHub Project é a fonte oficial do andamento das tarefas.
- As Issues são a fonte oficial do trabalho planejado.
- As Pull Requests são a fonte oficial das alterações realizadas.
- Os documentos desta pasta são a fonte oficial das regras de gestão do projeto.
